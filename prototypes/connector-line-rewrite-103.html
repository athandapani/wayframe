Connector-line rewrite

Prototype for wayframe#103 (ticket t25). Question: what replaces today's 3-waypoint buildConnectorPath — elbow/s-curve/rounded, all from the same two endpoints and a naive geometric midpoint, zero collision avoidance, painted under markers?

Answer built here: zone-aware column sweep, not general pathfinding. The connector's vertical elbow segment queries the SAME per-lane tier-zone occupancy #101/t24's createZone allocator already tracks (dates/ghosts/titles) — a read-only occupiesX query, no new layout pass. If the naive midpoint column is already clear, nothing changes. If not, it sweeps outward in fixed 8px steps toward whichever side has more slack, capped at 6 tries (~48px), then gives up and falls back to the naive midpoint rather than build a zigzag path around every obstacle. Paint order changes by half: connectors now render above the tier-zone chips they cross, but stay below markers — so a rare undodged overlap shows the line winning, not vanishing.
